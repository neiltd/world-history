# World History Explorer

A public pilot of one historical moment: Potosí, 1573. Explore it on a map, or read it closely in Research mode.

Live site: https://neiltd.github.io/world-history/

This repository holds only the built site. The content is a pilot and has not yet been reviewed by a historian. Every Claim and Source on the site has a way to report something that looks wrong; each report is checked against the cited Source before anything changes.

Made by neiltd, with the help of AI tools for design, code and checking.
